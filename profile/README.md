## 🧰 What we build

Practical, production-minded code for developers who want to skip the boilerplate:

- **Starter kits & boilerplates** — backend-first setups with auth, DB, and deployment already wired up
- **Self-hosting products** — tools you run on your own infrastructure, no vendor lock-in
- **Dev utilities** — small, focused tools built to solve one problem well

Everything here favors  backends over heavy frontend frameworks, with Docker and CI baked in from day one.
